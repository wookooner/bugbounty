# TGT-0001 남은 검토 계획

기준은 OpenZeppelin Contracts v5.7.0 커밋 `cab19933c33c2ad1d4c7a84864a3601dddfd16f3`다. 기본 역할 관리, 기본 관리자 이전, Timelock 초기 관리자와 지정 실행자, 예약·취소, 선행 작업, 공개 단건 실행을 확인했다. ETH 전달은 기존 로컬 테스트의 1 wei 사례로 확인했다. [범위](scope.md) · [현재 기록](research_logs/REVIEW.md)

| 순서 | 남은 검토 | 완료 기준 | 상태 |
| --- | --- | --- | --- |
| 0 | 공식 정책과 범위 재확인 | 검토 날짜와 적용 자산·허용 환경·영향 기준 기록. 웹·API·지갑 UI나 다른 배포는 공식 범위와 연결 근거가 있을 때 계획에 반영 | 완료 |
| 1 | Timelock 공개 실행의 배치 동작 | 지정·공개 실행 구성에 대한 기대 결과를 적고, 정상적으로 예약된 배치의 실행 권한과 완료 상태를 로컬 테스트로 확인 | 완료 |
| 2 | 배치 결과와 상태 경계 | 기존 테스트에서 시간 경계, 취소 후 상태, 배치 실패 시 상태·이벤트·잔액의 기대값과 관찰값을 확인하고 남은 검증 공백을 표시 | 완료 |
| 3 | 공개 자료 대조 및 소스 검토 마감 | 관련 공개 권고·감사 자료를 확인하고 상태 문서와 JSON 기록을 갱신. 확인된 영향이 있을 때만 영향과 심각도 근거를 추가 | 완료 |
| 조건부 | 실제 배포의 운영 권한 검토 | 공식 범위에서 확인한 체인·주소와 기준 블록을 고정한 뒤 초기 설정 관리자, 제안·취소·실행 역할 및 지연 설정을 읽기 전용으로 확인. 관련 웹·서명·운영 구성은 범위가 확인된 경우만 연결 | 배포 식별자 필요 |

0~3번을 완료했다. 운영 설정 검토는 공식 범위에서 확인한 배포 식별자가 필요하다. 현재 활성 가설과 확인된 취약점은 없다. [마감 기록](research_logs/2026-11-24-timelock-batch.md)
